# Contributing

Thank you for contributing!

## Workflow

1.  **Install Dependencies:**
    ```bash
    dart pub get
    ```

2.  **Format Code:**
    ```bash
    dart format .
    ```

3.  **Run Analysis:**
    ```bash
    dart analyze
    ```

4.  **Run Tests:**
    ```bash
    dart test
    ```

## Expectations

- Changes should include tests.
- Public API changes should be documented in `README.md` and `CHANGELOG.md`.
