# Working Notes

Working notes are temporary, exploratory, or historical notes created during development. They are used to capture thinking that isn't yet ready for the Handbook or an ADR.

## Purpose

- Research notes and investigation logs.
- Planning sketches and temporary implementation thoughts.
- Debugging notes and experiment results.
- Migration notes and unconfirmed ideas.

## Authority

Working notes are **non-authoritative** by default. They represent "work in progress" or historical context. Once a decision is finalized or a workflow is established, it should be promoted to the Handbook or an ADR.

## Promotion Path

A working note may be promoted into:
- A **Handbook page**, if it describes current accepted behavior.
- An **ADR**, if it records a significant decision.
- A **Changelog entry**, if it describes a completed change.
- An **Issue or Task**, if it describes future work.

## Filename Format

`YYYY-MM-DD-topic.md` (e.g., `2026-05-04-auth-investigation.md`)
